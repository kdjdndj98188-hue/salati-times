# 🕌 صلاتي – مواقيت الصلاة

موقع عربي مجاني لعرض **مواقيت الصلاة اليومية والشهرية** في جميع الدول والمدن العربية، بتصميم إسلامي أنيق من اليمين إلى اليسار، ومتوافق مع الهاتف والكمبيوتر.

> Salati – Free Arabic (RTL) prayer times website for all 22 Arab countries, with countdown, Hijri date, monthly view and reminders. No dependencies, a single HTML file.

---

## ✨ المميزات

- مواقيت الفجر والظهر والعصر والمغرب والعشاء، مع الشروق منفصلًا
- عداد تنازلي مباشر للصلاة القادمة وتمييزها بالذهبي
- التاريخ الهجري (أم القرى) والميلادي، والساعة بتوقيت المدينة المختارة
- الدول العربية الـ22 ومدنها الرئيسية مع بحث سريع عن أي مدينة
- تحديد الموقع الجغرافي بإذن المستخدم
- 10 طرق حساب (أم القرى، رابطة العالم الإسلامي، الهيئة المصرية، المغرب، تونس، الجزائر، الكويت، قطر، كراتشي، أمريكا الشمالية)
- اختيار مذهب العصر (جمهور / حنفي)
- جدول شهري مع تنقل بين الشهور
- تنبيهات لكل صلاة على حدة (أثناء فتح الصفحة)
- وضع ليلي ونهاري، وزر مشاركة المواقيت
- حفظ المدينة والإعدادات محليًا في المتصفح
- لا يحتاج خادمًا ولا مكتبات ولا API

## 📁 ملفات المشروع

| `prayer-times-2027.json` | مواقيت سنة 2027 لـ 64 مدينة، جاهزة لأي تطبيق |

## 🚀 التشغيل والنشر

**محليًا:** افتح `index.html` في المتصفح مباشرة.

**على GitHub Pages:**
1. ارفع الملفات إلى مستودع عام (Public).
2. من **Settings ← Pages** اختر Branch: `main` و `/ (root)` ثم **Save**.
3. سيظهر الموقع على `https://USERNAME.github.io/REPO`.

يعمل أيضًا كما هو على Cloudflare Pages وNetlify وVercel.

## 🧮 طريقة حساب المواقيت

تُحسب المواقيت **فلكيًا داخل المتصفح** من خط العرض والطول وموقع الشمس لكل يوم، مع مراعاة المنطقة الزمنية والتوقيت الصيفي للمدينة. تعتمد الطريقة المختارة زوايا الفجر والعشاء، ويحدد المذهب ظل العصر.

> قد تختلف النتائج دقيقة إلى دقيقتين عن التقويم الرسمي في بلدك؛ يُرجى الاعتماد على الجهة الرسمية عند الحاجة. التاريخ الهجري وفق تقويم أم القرى وقد يختلف يومًا عن رؤية الهلال المحلية.

## 📦 استخدام ملف البيانات

```js
const data = await fetch('prayer-times-2027.json').then(r => r.json());
const city = data.cities.find(c => c.city === 'مكة المكرمة');
const dayOfYear = 0;                 // 1 يناير = 0
const [fajr, sunrise, dhuhr, asr, maghrib, isha] = city.times[dayOfYear];
```

- `times[i]`: أوقات اليوم رقم `i` بتوقيت المدينة المحلي (24 ساعة).
- `asrHanafi[i]`: وقت العصر بالمذهب الحنفي.
- الترتيب في الحقل `order`، وتفاصيل الطرق في الحقل `methods`.

## 🔒 الخصوصية

لا يجمع الموقع أي بيانات ولا يرسل شيئًا إلى أي خادم. الموقع الجغرافي يُستخدم داخل المتصفح فقط، والإعدادات تُحفظ في `localStorage`.
